Поиск среди собственных Скаутинг-отчётов пользователя. Для вопросов «что я писал про X»,
«найди мой отчёт по X», «какие отчёты я делал», «покажи мои разборы центровых» — про то, что
пользователь уже заказывал раньше.

Ищет по смыслу резюме отчётов (имя игрока, сезон, архетип, резюме) только среди отчётов самого
пользователя; чужих отчётов не видно и найти нельзя. Если вопрос про конкретного игрока, передай
`player_name` (латиницей) — поиск ограничится отчётами по нему. Это не поиск по корпусу
(`search_corpus`) и не источник статистики: сам отчёт на страницу не приходит, только резюме.

Результат: `reports` — до пяти отчётов по убыванию близости (`similarity`, косинус). У каждого
`report_id`, `player`, `season`, `archetype`, `summary`, `created_at`, `url` (страница отчёта).
Пользователь видит их карточкой со ссылками. Выдача ранжирована, но не отфильтрована: пять
ближайших вернутся, даже если отчётов по нужному игроку нет. Поэтому проверяй `player` и `season`
в каждом: если среди результатов нет отчёта, о котором спрашивали, так и скажи — что отчёта по
этому игроку у пользователя нет — и предложи создать (`create_scouting_report`). Пустой
`reports` значит, что у пользователя вообще нет отчётов.

Отвечай только тем, что есть в `summary`, `archetype` и датах; подробностей, которых в резюме нет,
не додумывай — отсылай на страницу отчёта по `url`.
