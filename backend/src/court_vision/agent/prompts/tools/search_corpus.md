Поиск по корпусу баскетбольных текстов: официальные правила NBA (`rulebook`) и статьи
Wikipedia об истории и терминах игры (`wikipedia`). Возвращает цитаты с номерами `n` —
опирайся на них в ответе маркерами `[n]`.

Запрос формулируй по-английски: корпус английский, и запрос на другом языке не найдёт
ничего. Спрашивай терминами игры (`goaltending rule`, `shot clock history`), а не целой
фразой пользователя.

Когда вопрос про формулировку или трактовку правила, передавай `source="rulebook"` —
эксперт по правилам отвечает по тексту правил, а не по пересказу. Для истории, терминов
и контекста подойдёт `source="wikipedia"`; без `source` ищется по всему корпусу.
