# Court Vision — AI-ассистент баскетбольного скаута

## Продукт

Backend-сервис для аналитики NBA: отвечает на вопросы об игроках и матчах на естественном языке, генерирует скаутинг-отчёты, сравнивает игроков и присылает ежедневные дайджесты результатов. Под капотом — LLM-агент с доступом к статистической базе и RAG-поиском по текстовому корпусу (статьи, правила, заметки). Пет-проект для портфолио: демонстрирует полный стек современного AI-бекенда.

## Ключевые возможности

- **Q&A с цитатами** — вопросы в свободной форме, ответы с ссылками на источники (RAG)
- **Скаутинг-отчёты** — структурированный разбор игрока/матча из сырой статистики (structured output, streaming)
- **Агент с инструментами** — сам решает, какие данные достать: `get_player_stats`, `compare_players`, `search_reports`
- **Ежедневный дайджест** — фоновый sync результатов + LLM-сводка с уведомлением
- **Eval-сьют** — 30–50 эталонных вопросов, LLM-as-judge, регрессионные прогоны при смене промптов/моделей

## Технологии

- **Язык/фреймворк:** Python, FastAPI
- **БД:** PostgreSQL + pgvector (единая база: реляционка + векторный поиск), JSONB для сырых payload'ов
- **LLM:** мультипровайдерная абстракция с фолбэком (Anthropic / Gemini / Groq), дешёвые модели по умолчанию, кеширование ответов, подсчёт стоимости токенов
- **Поиск:** гибридный (векторный + полнотекстовый tsvector), реранкинг
- **Асинхронщина:** Celery/arq + Redis (воркеры, крон-задачи, rate limiting, кеш)
- **Наблюдаемость:** структурные логи, трейсинг LLM-вызовов (токены, латентность, стоимость), Langfuse опционально
- **Инфра:** Docker Compose, JWT-auth, CI (GitHub Actions), деплой Railway/Fly.io

## Данные

- **Исторические (основной массив):** Kaggle-датасеты NBA (матчи, box scores, статистика игроков) → разовый seed в Postgres
- **Свежие:** balldontlie API, free tier (teams/players/games, 5 req/min) → ежедневный sync 1–3 запросами, паттерн cache-aside
- **Текстовый корпус для RAG:** Wikipedia (игроки, команды), официальный rulebook NBA (PDF), собственные заметки → chunking → embeddings → pgvector
- **Абстракция:** интерфейс `DataProvider` с реализациями `LocalProvider` (Postgres) и `BalldontlieProvider` (внешний API, fallback)
