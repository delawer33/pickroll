# Vertical slices вместо слоёв и Clean Architecture

Код организован по фичам (package by feature: модуль = домен, внутри свои router/service/models/schemas), а не по техническим слоям и не по канонам Clean Architecture. Сервисы — функции с явными зависимостями, работающие с SQLAlchemy напрямую; репозитории, use-case-классы и порты-адаптеры сознательно не используются — абстракция допустима только у швов с реальной второй реализацией (`DataProvider`, LLM-транспорт). Причина: на нашем размере кодовой базы церемония гексагональной архитектуры не окупается, а низкая связность слоёной структуры размазывает каждую фичу по нескольким папкам; фича-модуль дополнительно является естественной единицей работы для агентов, проектирующих спринты. Не «чините» это добавлением репозиториев — отсутствие прослоек здесь намеренное.
