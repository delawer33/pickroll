# litellm как транспорт, свой агентный цикл поверх

Мультипровайдерность (Anthropic / Gemini / Groq) — заявленная возможность системы, и был соблазн либо написать адаптеры провайдеров руками, либо взять агентный фреймворк целиком (pydantic-ai, LangChain). Решили разделить: litellm нормализует форматы провайдеров и даёт колбэк в Langfuse, а агентный цикл, инструменты, фолбэк-политика и учёт стоимости — собственный код, потому что это смысловое ядро проекта и место, где нужен полный контроль. Ручные адаптеры отвергнуты как механическая работа без демонстрационной ценности; полный фреймворк — потому что отдаёт ему самую интересную часть системы.
